# 机器人

一台机器人一个目录。目录名就是站点名：全团队唯一，定下来就不改。目录里每个文件是做什么的，见 [本仓库是怎么组织的](../docs/how-it-works.md#一台机器人一个目录)。

| 站点 | 电脑 | 负责人 | 现在 |
| --- | --- | --- | --- |
| `yam_1` | `ubuntu1` | ningma | 相机已登记；CAN 适配器还没插；没调参 |
| `yam_2` | `ubuntu2` | ningma | 设备已登记；CAN 对手臂、相机对位置还没做；没调参 |
| `yam_3` | `ubuntu3` | ningma | 设备已对上；两条跟随臂已调参；左主臂可换成 GELLO（`station_gello.toml`，已标定）；相机时有掉线 |
| `tron2_1` | 待定 | 同事 | 还没接入 |

- `_shared/`：所有 YAM 共用的遥操作配置。
- `_archive/`：已经退役的站点，只作参考。

文件里写着 `FILL` 的地方，是还没在现场确认的事实。留着 `FILL`，那台设备就打不开，所以不会因为填错而录错数据。
