# 飞书机器人（xirra）

团队的飞书助手，跑在中心服务器上，读 xpisode 的中心数据。怎么装、怎么配、怎么重启，看 [在中心服务器上跑团队服务](../../docs/guides/central-server.md)。

## 它能做什么

在飞书里私聊它，或在群里 @ 它：

- **进度**：进行中的采集、评测计划，各还差多少
- **今天** / **昨天**：当天传到 OSS 的录制，按站点、按人
- **我** / **人 名字**：最近 7 天的采集时长
- **任务** / **任务 名字**：任务列表；某个任务的中文说明和给模型的英文指令
- **日报**：每天定时发到一个群，也可以随时要一份
- **我是谁**：第一次用时从人员名单里选自己
- 其他问题直接问：它用只读工具查数据，回答附上记录 id
- 让它建任务、采集计划、数据集，或结束一个计划：它发一张卡片，提出的人点「确认」才写入

数据以已经传到 OSS 的为准。

## 代码

| 文件 | 做什么 |
| --- | --- |
| `src/xirra/bot.py` | 飞书长连接、消息、卡片按钮、日报 |
| `src/xirra/answers.py` | 固定命令的回答 |
| `src/xirra/llm.py` | 自由提问（大模型加只读工具）、任务说明的中文翻译 |
| `src/xirra/proposals.py` | 写入的提议、确认、执行 |
| `src/xirra/panel.py` | 读面板、写中心数据目录 |
| `src/xirra/team.py` | 团队情况：站点、任务、人，从 `robots/` 和记录里读，不手写 |
| `src/xirra/forms.py` | 表单卡片：建计划、建数据集、你是谁 |
| `deploy/` | 配置模板、常驻运行脚本、中心数据目录脚本 |

测试：`uv run pytest`。
