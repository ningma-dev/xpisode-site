# 装一台 GELLO 主臂

GELLO 是用 7 个小舵机做的示教主臂（abc 开源的设计），操作员拿着它，跟随臂照着动。每台 GELLO 装好后要做两件事：给舵机设编号，再标定一次。标定就是让程序记下每个关节的零点、往哪边转是正，以及扳机松开和捏到底的位置，存成一个文件，以后启动时读它。**没标定过的 GELLO 打不开。**

**什么时候做：** 新装好一台 GELLO；拆过舵盘（舵机上带齿的圆盘）重新装上；换了舵机。

**前提：**

- 站点文件里已经有这台 GELLO 的设备，写好了 U2D2 序列号、7 个舵机编号和标定文件的位置。可以照抄 `robots/yam_3/station_gello.toml` 里的 `leader_l`，换成这台的值。编号的分配规则：第几只臂 × 10 + 关节号，比如第 1 套左臂是 10–16。
- `host/doctor.sh` 能跑通。U2D2 插在这台电脑上，GELLO 的电源是 5 V（插错 12 V 会烧舵机）。
- 站点没有在运行：同一时间只能有一个程序用 U2D2。

下面的命令都在 `~/xpisode-site` 里运行。`leader_l` 换成站点文件里这台 GELLO 的设备名。设备不在 `station.toml` 里时，每条命令后面加 `--file <站点文件名>`。这些命令都不会让手臂动，也不会打开相机。

## 1. 设舵机编号

新舵机出厂编号都是 1，一起接上会冲突，所以要一边接线一边设，一次只多接一个。

1. 关掉 GELLO 的电源，只接上 M1（肩部，关节号从 0 开始，底座是 M0），打开电源，然后运行：

   ```bash
   scripts/gello.sh leader_l ids set M1
   ```

   **成功的样子：** 打印 `M1: id 1 at 57600 -> id 11 at 2000000`，编号是站点文件里写的那个。

2. 关电源，接上下一个舵机，重复上一步，依次是 M2 到 M6。最后接 M0（它单独接在电源板上）。
3. 检查：

   ```bash
   scripts/gello.sh leader_l ids scan
   ```

   **成功的样子：** 7 行，`M0` 到 `M6` 都在，没有 `not set up`。

扫描不到任何舵机，多半是电源没开或者 U2D2 到电源板的线松了。只有新接的那个不见了，多半是它前面那根线没插紧。

## 2. 标定

程序会一步一步提示，每步做完按回车。舵机不上力，GELLO 全程用手动。"正方向"都按站在手臂后面、和夹爪朝同一个方向看来描述。

```bash
scripts/gello.sh leader_l calibrate
```

1. **零位**：把 GELLO 摆成 YAM 的零位，也就是完全折叠、夹爪朝前，扳机松开。
2. **逐个关节**：程序每次让你从零位把一个关节往指定方向转大约 45 度并保持住，其他关节别动，然后放回零位：
   - 关节 1（底座）：向左转；
   - 关节 2（大臂）：抬起；
   - 关节 3（小臂）：抬起，把肘部展开；
   - 关节 4（手腕俯仰）：夹爪尖往上翘；
   - 关节 5（手腕偏航）：夹爪尖往右转；
   - 关节 6（手腕滚转）：从后往前看顺时针转，也就是夹爪左侧往上。
3. **扳机**：手臂保持零位，把扳机捏到底。
4. **最后检查**：松开扳机，放回零位，程序会打印每个关节的读数，应该都接近 0。

某一步没做对，比如转得太少、带动了别的关节，程序会说明原因，让你重做这一步。它说"另一个关节的舵机动得最多"，就是两个舵机的编号装反了：回到第 1 步重新设编号。

**成功的样子：** 最后一行是 `wrote robots/<站点>/tuned/gello_leader_l.json`（文件名以站点文件里写的为准）。

## 3. 检查

```bash
scripts/gello.sh leader_l check
host/doctor.sh
```

**成功的样子：** `check` 显示总线约 400 Hz、`retries 0`，转动关节时读数跟着变。体检里 `gello` 一项是 PASS。

做完在 `robots/<站点>/LOG.md` 里记一条，然后提交、推送标定文件。

## 之后启动

GELLO 摆成什么姿势都能启动，不用每次先摆零位。启动时它会核对标定文件是不是这台 GELLO 的（U2D2 序列号和舵机编号），对不上就拒绝启动。
