# 认出每个设备

电脑能看到每个 CAN 适配器、每台相机的序列号，但不知道哪个适配器接的是哪条手臂、哪台相机装在哪个位置。这一篇就是把这些对上，写进 `robots/<站点>/`。

**什么时候做：** 第一次装机；换了适配器、换了线、换了相机之后。

**要求：** 人在机器旁边，只拔插 USB 线。手臂不会动，相机不会被打开，站点不用启动。

所有命令都在 `~/xpisode-site` 里运行。

## 先记住一件事

序列号认的是**适配器**，不是手臂。适配器从左臂换到右臂，系统发现不了，因为左右两条手臂在总线上看起来一模一样。所以：

- 每个适配器和它的线都**贴上手臂名**，两者一直绑在一起；
- 不要按插口顺序猜。一定要一个一个拔下来确认。

## 1. 看看现在插着什么

```bash
host/xhci_list.sh
```

它列出每台相机和每个 CAN 适配器：序列号、插在哪个 USB 口。只是列出来，不会打开它们。

## 2. CAN 适配器对手臂

YAM 有四条手臂：`follower_l`（左跟随臂）、`follower_r`（右跟随臂）、`leader_l`（左示教手柄）、`leader_r`（右示教手柄）。

每条手臂做一遍：

1. 顺着这条手臂的线，找到它的适配器，拔下 USB；
2. 运行 `host/can_list.sh`，少了的那个序列号就是这条手臂的；
3. 给适配器和线贴上手臂名，插回去。

然后打开 `robots/<站点>/can.toml`，把四个 `"FILL"` 换成对应的序列号。

先预览一下要写进系统的规则（这一步只显示，不会改任何东西）：

```bash
host/can_rules.py <站点> --check
```

**成功的样子：** 显示四行规则，每行把一个序列号命名为 `can_<手臂名>`。如果提示有序列号没填或重复了，回去再核对一遍。

确认没问题，生效：

```bash
sudo host/can_rules.py <站点>
```

## 3. 相机对位置

YAM 有三台相机：`cam_head`（头顶）、`cam_left_wrist`（左手腕）、`cam_right_wrist`（右手腕）。

每台相机做一遍：

1. 顺着线拔下这台相机的 USB；
2. 运行 `host/xhci_list.sh`，少了的那个序列号就是它；
3. 插回去。

然后打开 `robots/<站点>/station.toml`，把 `FILL_cam_head_serial` 这类占位换成对应的序列号。每台相机在文件里出现两次，两处都要换。

## 4. 检查

```bash
host/doctor.sh
```

**成功的样子：**
- `can-links` 是 PASS：四个 `can_<手臂名>` 都已启用；
- `station-file` 是 PASS：相机序列号都填上了；
- `irq-layout` 是 PASS。如果它是 FAIL，说明设备换过插口，`machine.env` 里记的已经和实际不一样了。按它提示的内容更新 `robots/<站点>/machine.env`，再运行一次 `host/doctor.sh`。

适配器名字没有变：把那个适配器拔下来再插上，或者重启。

## 5. 记下来

在 `robots/<站点>/LOG.md` 里记一条，写上每个对应关系，和改过的文件一起提交、推送。
